Infrastructure Access

CIROH provides access to public cloud services, HPC, and on-premises infrastructure to support the research projects of CIROH's members and partners.

info

To access the formal policy informing the below guidance, please see the Standard Operating Procedures for CIROH Cyberinfrastructure.

Public Cloud

Accessing Public Cloud Services

CIROH has partnered with AWS and Google Cloud to provide access to their cloud computing services. Review the linked documentation for account request steps and guidance.

Getting Started

1

Requesting Project Access

Primary Investigators (PIs) or Workshop Leads leading CIROH projects or workshops can request public cloud resources through the provider-specific forms below. Choose AWS or Google Cloud based on where you want the resource provisioned.

AWS Resource

Provision CIROH AWS resources for your project.

Use this form when you need AWS services such as EC2, S3, EBS, RDS, VPC, or other AWS-managed infrastructure.

Create AWS Request

GCP Resource

Provision CIROH Google Cloud resources for your project.

Use this form when you need Google Cloud services such as Compute Engine, Cloud Storage, BigQuery, GKE, VPC, IAM, or related tooling.

Create GCP Request

Your Responsibilities

CIROH Consortium members or partners are responsible for:

  • ✓Management of CIROH subaccounts assigned to them
  • ✓Project-specific software and environment configuration
  • ✓Handling account creation and/or access for project contacts

Cost of Use

  • ★Use of CIROH-2i2c JupyterHub is free for all consortium projects
  • $Individual projects are allotted $500 monthly for AWS and Google Cloud
  • ⚠Projects exceeding budget may request additional funds below
Request Additional Budget
Cloud Computing

Accessing CIROH-2i2c JupyterHub

In partnership with 2i2c, CIROH provides JupyterHub with both CPU and GPU capabilities. See the 2i2c server options documentation for configuration details.

Getting Started

1

Submit Unified Access Request

The PI for your project must submit the Infrastructure Request Form below to request team-wide access to a particular resource on 2i2c JupyterHub.

Cloud Infrastructure Request Form

Requesting Custom Images

To request custom images or software updates:

  1. Optionally create an environment.yml file by exporting your conda environment.
  2. Open a ticket in the CIROH image repository and describe the software or image changes you need using the link below.
Custom Image Ticket
On-Premises HPC

Accessing On-Premises Infrastructure

CIROH operates an on-premises infrastructure that includes high-performance computing (HPC) resources and specialized software via the Pantarhei and Wukong systems. See the Pantarhei documentation for system details.

Getting Started

1

Submit Project Access Request

Primary Investigators (PIs) leading CIROH projects may use this form to request CIROH on-premise resources for their teams, including Pantarhei and Wukong.

On-premises Infrastructure Request Form
2

Request Individual Access

Non-UA users should complete the VPN Access Request section of the form before proceeding to the On-Premise Access Request section.

On-Premise Access Request Form
High-Performance Computing

NSF ACCESS Allocations through CIROH

In collaboration with NSF ACCESS Allocations, CIROH offers access to all the resources that are available through an allocation on the Resources. This guide will walk you through the steps necessary to gain access to any resources using your NSF ACCESS allocation. For more information, review the NSF ACCESS documentation.

Getting Started

1

Register for ACCESS Allocation

If you don't already have an ACCESS Allocation account, register for one using the link below.

ACCESS Allocation New User Registration
2

Submit Infrastructure Request

The PI for your project must submit the Infrastructure Request Form below to request team-wide access to a particular resource on ACCESS Allocation.

Infrastructure Request Form

You're All Set!

Once you're granted access, you're ready to begin using the resources!

Visit Your ACCESS Resources Page

Accessing NWM BigQuery API
